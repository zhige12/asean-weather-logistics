# 系统架构图与数据使用说明

## 一、总体架构图

> 分层成图见配套 **《09-系统架构图-分层版.png》**（四层鸟瞰）与 **《08-系统架构图.png》**（气象驱动决策主线）。此处保留技术细节清单：

- **① 应用与交互层**（Vue 3 + Leaflet，移动端 Capacitor；界面语言中/越/英三语）：调度大屏（路网态势/熔断可视化/决策沙盘/六维方案对比/AMRI 可解释风险面板/中越英三语预警海报/叫应看板/日志回溯）、司机端（任务接收/中越双语 TTS 语音/ETA 修正/换线确认）、公众模式。
- **② 服务与接入层**（Spring Boot）：REST `/api/**`、SSE `/api/agent/events`、同源瓦片代理（密钥不出后端）、公网演示护栏（危险接口屏蔽 + per-IP 限流）。
- **③ 智能体层**（只生文字不生数字）：RiskAgent → SolutionAgent → TouchAgent 顺序编排；知识库加权匹配；兜底链本地 Ollama → 在线 DeepSeek → 离线文案池/规则模板，前置**有界并发闸**（超上限快速失败降级、拒绝计数随 `GET /api/ai/metrics` 透出），通道如实标注。
- **④ 图计算与风险引擎层**（全部对外数字在此产生）：邻接表 + Dijkstra 阶跃惩罚硬熔断；路网装载与口岸断边修复；全要素代价 + 行驶进度闸门 + ETA；公—水双向互备评估【创新点】。
- **⑤ 数据层**：路网/知识库/通关时效；三气象源可切换（官方 CRA40 主源）；缓存 + 60s 最小回源 + 连续失败熔断；瓦片两级缓存。

贯穿全链的可核验机制：人在回路确认、AI 与气象来源标签、频度合规统计端点、前端零密钥、决策日志留痕。

## 二、核心决策链路（时序）

气象数据(CRA40) 注入降雨/能见度/流速/浪高 → RouteService 阶跃惩罚改边权（≥100 硬熔断）并毫秒级重算 → 熔断清单与决策边界下传三智能体 → RiskAgent→SolutionAgent→TouchAgent 顺序产出解释文字 → 大屏展示六维方案对比（耗时/风险/货损/油耗/费用/碳排）→ 调度员人工确认 → SSE 下发差异化指令至司机/船长/百姓端 → 确认回执回流（未确认自动升级渠道）。

## 三、公—水动态边权共生模型

同一张有向图内公路边与水运边共享边权内核：南宁→凭祥/友谊关、百林/东兴（芒街）、合浦/运河三条公路走廊，与六景港→海防港水运边并行存在。友谊关 12h 累计降雨超 80mm 即 penalty=100 熔断；运河能见度低于 1000m 即禁航。公路熔断时引擎自动评估水运边可行性，水运禁航时反向核算公路绕行代价，实现双向共生备份。

## 四、数据使用说明

| 数据集 | 来源 | 授权/合规 | 在系统中的作用 | 是否含个人/敏感数据 |
|---|---|---|---|---|
| 中越跨境路网（`vietnam-road-network.json`） | OpenStreetMap 开源数据，团队自主清洗 + 口岸虚拟边修复 | ODbL 开源许可，需署名 | 图计算拓扑基础、路径规划载体 | 否 |
| 气象网格数据 | 大赛官方 CRA40 实况/预报接口（备源 Open-Meteo 公开气象） | 官方接口授权 / CC-BY 4.0 | 驱动动态边权熔断、风险研判输入 | 否 |
| 通关时效数据 | 政府公开公报、口岸运行公告整理 | 公开信息 | 方案耗时测算、拥堵评估 | 否 |
| 行业知识库（`knowledge-base.json`） | 《平陆运河通航安全管理规定》、跨境物流规范、企业规则 | 公开法规/自整理 | AI 决策解释依据、RAG 检索源 | 否 |
| 地图底图瓦片 | 天地图（同源代理）/ OSM / 本地矢量瓦片 | 天地图密钥授权、OSM 开源 | 大屏与司机端可视化 | 否 |
| 演示用货运数据 | 团队构造的模拟任务（司机、货物、船期） | 虚构样本 | 案例演示、任务下发闭环 | 否（全部虚构，不含真实个人信息） |

**数据合规声明：**
1. 全部敏感密钥（气象 Token、天地图密钥池、云端大模型 Key）仅存后端环境变量，前端与构建产物零密钥。
2. 核心 AI 推理与路径计算优先在本地 Ollama 完成；本地可用时业务数据不出硬件设备，符合《数据出境安全评估办法》。仅本地推理不可用且处于联网状态时，按降级链调用云端作为兜底。
3. 演示与测试数据均为团队构造，不涉及真实个人隐私与商业秘密。
4. OSM 派生数据遵循 ODbL 署名要求。
