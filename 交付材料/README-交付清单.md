## 提交前必做（直接影响“可复现”判定）

1. **补齐未入库的源码文件**（缺任何一个，评委 clone 后编译不过）：
   `src/main/java/.../service/CorridorAdvisoryService.java`、`src/main/java/.../service/RecommendationPool.java`、
   `frontend/src/utils/corridorAdvisory.js`、`src/test/java/.../service/SolutionAgentDetourTriggerTest.java`。
2. **入库本目录的成图与截图**：`10`～`13` 的 html/png 与 `_ui/` 目前仍为未跟踪状态，需一并 `git add`。
3. **仓库只提交 `.env.example`**：根目录 `.env.local` 已被 `.gitignore` 排除，以 Git 仓库地址提交时凭证不会跟着出去。
   注意与 Demo 包的区隔：可运行 Demo 包内的 `asean-demo/.env.local` **为让评委开箱核验而内含申请人本人三份凭证**，
   该目录不入库，且包只定向交付评审人员——不得上传公开网盘、群发链接或传到仓库。
4. **展示结束后立即作废并轮换三份凭证**（天地图 / DeepSeek / 气象 Token）：它们已随 Demo 包外发，
   应视为已扩散；新值只写本机 `.env.local`，不写进任何文档与交付包。
5. **提交前自检**（三条都应为空或成功）：
   ```bash
   git grep -n -E "(TOKEN|_KEY|KEYS|_TK)[=:][0-9a-zA-Z]{8}"   # 仓库内无凭证
   git status --short                                          # 无 ?? 状态的源码与交付物
   gradlew.bat build && cd frontend && npm ci && npm run build # 后端与前端均可构建
   ```

## 你仍需线下完成的 4 件事（⛔/🟡）
1. **官方承诺书附件2**：向主办方下载原始模板 → 填写 → 签字盖章 → 扫描 PDF。
2. **可运行 Demo 入口**：按 `05` 文档部署（公网或局域网）并提供链接，或上传 `app-debug.apk` + 后端运行说明。
3. **5 分钟演示视频**：按 `05` 分镜脚本，用大屏+手机实录导出 MP4。
4. **知识产权佐证**：建议准备——
   - 软件著作权登记证书（或受理通知书）；
   - 代码查重/AIGC 检测报告（若赛事要求）；
   - 开源许可清单：Spring Boot(Apache-2.0)、Vue(MIT)、Leaflet(BSD-2)、Capacitor(MIT)、GraphHopper(Apache-2.0)、JGraphT(EPL/LGPL)、Ollama(MIT)、Qwen(通义千问协议)、OSM 数据(ODbL 署名)；
   - 若已申请发明专利/实用新型，附受理或授权文件。
