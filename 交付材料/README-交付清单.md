## 你仍需线下完成的 4 件事（⛔/🟡）
1. **官方承诺书附件2**：向主办方下载原始模板 → 填写 → 签字盖章 → 扫描 PDF。
2. **可运行 Demo 入口**：按 `05` 文档部署（公网或局域网）并提供链接，或上传 `app-debug.apk` + 后端运行说明。
3. **5 分钟演示视频**：按 `05` 分镜脚本，用大屏+手机实录导出 MP4。
4. **知识产权佐证**：建议准备——
   - 软件著作权登记证书（或受理通知书）；
   - 代码查重/AIGC 检测报告（若赛事要求）；
   - 开源许可清单：Spring Boot(Apache-2.0)、Vue(MIT)、Leaflet(BSD-2)、MapLibre GL(BSD)、Capacitor(MIT)、GraphHopper(Apache-2.0)、JGraphT(EPL/LGPL)、Ollama(MIT)、Qwen(通义千问协议)、OSM 数据(ODbL 署名)；
   - 若已申请发明专利/实用新型，附受理或授权文件。
