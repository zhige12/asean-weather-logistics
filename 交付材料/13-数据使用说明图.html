一、数据流向密钥只在后端一处，前端与 APK 构建产物零密钥

① 上游数据源

赛事官方 CRA40 实况 / GOWFS 3h 预报接口、Open-Meteo 公网气象、OSM 开源路网与瓦片、天地图瓦片服务、公开法规与口岸公报

② 后端唯一持密处

Token / 密钥池 / 大模型 Key 只从 .env.local（已 gitignore）与环境变量读入；节流、熔断、缓存、审计计数全在这一层

③ 引擎计算

逐边惩罚 → 硬熔断 → A* 重算 → 三方案六维指标；所有对外数字在此产生，与模型无关

④ AI 只写文字

本地 Ollama 优先（数据不出境）→ 在线 DeepSeek → 历史文案池 → 规则模板，命中通道随文案标注

⑤ 界面呈现

REST + 一条 SSE 流喂大屏与司机端；瓦片走同源 /api/tianditu/…，密钥不进浏览器包

⑥ 回流与留痕

接单/拒单/叫应回执回流后端 → DecisionLogService 逐条落时间线，「原始返回」可核对接口原文

↺ ⑥ 的回执与在途进度（司机端约 30s 上报）重新进入 ③，形成"数据 → 决策 → 执行 → 新数据"的闭环

三、溯源与可核验机制每条结论都能查到来源、频度与原文

1来源与新鲜度分开标
  • 气象：界面所选源 selectedSource 与真正服务源 servedSource / servedFresh（是否本次取的）分开回显
  • 沙盘降雨：GOWFS 预报（真实） 或 模拟参数（可调） 原文标注
  • AI：通道标签只有 本地 / 在线 / 缓存 / 模板 四种原文，三智能体取"最远程"的通道汇总标注
2频度合规可查
  • /api/weather/rate-stats 与 /api/v1/rate-stats 输出四个审计计数：真实回源 / 缓存命中 / 节流拦下 / 熔断打开
  • 节流参数成文：实况 10 min 缓存、每源 60 s、跨源 5 s、连败 3 次静默 300 s；预报 30 min（静默 600 s）
  • 401 Token 失效立即熔断，静默期内一律 429，严禁重试轰炸上游
3结论可回溯
  • DecisionLogService 逐条留痕 10 类（FUSE / UNFUSE / WEATHER / SANDBOX / AGENT / TASK / DISPATCH / CONFIRM / ESCALATE / CONFIG），界面「决策日志」时间线经 GET /api/outreach/log 可查
  • 熔断日志带当时的雨量、阈值与触发源（「友谊关熔断 · 未来6h累计降雨量 120mm > 80mm 阈值，penalty=100（调度调整沙盘气象参数）」），同一口径的判险理由也写进被熔断边的风险逐段说明
  • 大屏「原始返回」可展开接口原文，与卡片数字逐格核对
4可复现取证
  • 界面证据：node tools/_ui_shots.mjs → node tools/_ui_pack.mjs（本套图的截图即由此产出）
  • 端到端：tools/_e2e_test.ps1、_geo_e2e.mjs、_wx_e2e.mjs、_task_sync_e2e.mjs 等脚本
  • 缓存预生成：tools/pregen_agent_cache.ps1

四、密钥与数据边界四类凭证、三道闸门、一条底线

钥四类凭证，全部只在后端
  • WEATHER_REAL_TOKEN（赛事气象）、TIANDITU_TK / TIANDITU_KEYS（密钥池）、DEEPSEEK_FALLBACK_KEY、预留 WATERWAY_OFFICIAL_TOKEN
  • 写法：application.properties 只留 ${VAR:} 占位，真值写本机 .env.local（已 .gitignore）
  • 未配置即视为"该通道未启用"并自动降级；自检接口 status() 只输出计数与守护状态，不含密钥/Token
闸公网演示三道闸门
  • 护栏过滤器：只拦 /api/ 下的非 GET（GET 与 SSE 全放行，节流 GET 等于节流演示）；改全局状态的写接口 20 次/分/IP，其余写接口 180 次/分，超限 429
  • 封死重负载入口：POST /api/routes/osm/start 会加载 311 MB OSM PBF，公网形态直接 403
  • CORS 白名单：仅 localhost / 127.0.0.1 / 内网段 / capacitor://localhost，禁止第三方站点借本服务转发上游请求
底一条底线：数据出境可控
  • 核心推理与算路优先在本机完成：路网、地名、知识库、瓦片缓存全部本地，断网可完整演示
  • 唯一会把业务内容送出本机的是在线大模型，且只在本地通道失败时才走，界面同步标「非本地」
  • 前端与 APK 构建产物零密钥：浏览器只请求同源 /api/tianditu/… 与 /api/v1/…（后者还要求携带与后端一致的 Bearer，第三方借不到额度）
三点说明： ① 真实预报与熔断阈值不同量级——CRA40/GOWFS 的真实 6h 累计降雨多为个位数至十余 mm，80mm 熔断演示由剧本值驱动，真实取数用于验证来源与链路，界面与本文口径一致； ② 越语文案为人工撰写底稿（待母语者校验）； ③ 官方水运调度平台尚未实际接入，当前以 mock 源验证同一接入链路，切换 official 不需要改动禁航判定与触达核心代码。 配套：图 1/2 系统架构（《08》《09》）看模块归属，图 5 业务流程（《12》）看这些数据在哪一步被消费。
