 面向东盟跨境物流的突发气象预警与多路线协同调度平台
 演示程序启动说明 —— 主入口：asean-demo-offline.zip（另附 exe 安装版可选）
═══════════════════════════════════════════════════════════════════════════

一、三分钟跑起来（压缩包版，共 4 步，全程不需要安装任何软件）

 1. 右键 asean-demo-offline.zip →「全部提取」，解压到桌面或任意普通文件夹，
    得到一个 asean-demo 文件夹。
    · 必须先解压再运行；不要只在压缩软件的预览窗口里双击，那样会提示 app.jar is missing。

 2. 进入 asean-demo 文件夹，双击 start.bat。会弹出一个黑色命令行窗口，那就是
    服务端，演示期间请一直开着它，关掉即停止。首次启动要加载路网，窗口里会滚
    日志，请耐心等 10~30 秒。
    · Windows 防火墙第一次会询问，勾选「专用网络」→「允许访问」。

 3. 约 25 秒后浏览器会自动打开调度大屏。没有自动打开就手动输入：
      调度大屏   http://localhost:8080/
      司机端     http://localhost:8080/driver.html
    建议用 Chrome 或 Edge，进入页面后按一次 Ctrl+F5 刷新一下。

 4. 演示结束：关掉那个黑色命令行窗口即可。

 （若您收到的是安装版 asean-demo-setup.exe：直接双击它，它会自动完成上面的解压与
   启动，效果与压缩包逐字节相同；两种入口任选其一。）


二、如果用安装版 exe 被打断（压缩包版不会遇到这两条）

 · 蓝色窗口「Windows 已经保护你的电脑」→ 点「更多信息」→「仍要运行」。
   原因：本程序未购买商业代码签名，它只做两件事：把跟在自身尾部的演示数据解压到
   同目录，再启动解压出来的 start.bat；不改系统设置、不联网下载、不写注册表。
 · 360／火绒把 exe 隔离或删除、双击没反应 → 改用压缩包版 asean-demo-offline.zip
   （右键「全部提取」→ 进 asean-demo → 双击 start.bat）。两个入口内容逐字节相同，
   压缩包形式不会被拦。


三、机器要求（三档；评委机器未知，系统会按真实性能自动适配）

 · 流畅·满特效：4 核及以上、内存 8GB 及以上、独立显卡或近 3 年主流集显；
   Chrome / Edge 最新版；磁盘空闲 ≥ 1.5GB。满足则大屏保持毛玻璃与路线流光等满特效。
 · 能跑·自动进轻界面（功能不减）：底线 Windows 10 版本 1809 及以上 64 位、2 核 / 4GB 内存。
   打开约 5 秒后系统实测帧率，若平均帧率 < 40fps 或出现 > 250ms 长帧，会自动关掉毛玻璃
   与流光等纯装饰特效（顶部按钮显示「⚡ 轻界面（自动）」），功能、数据、路线红绿分段、
   加载指示完全不变；也可点该按钮手动切换。
 · 内存自适应：start.bat 按本机物理内存自动设 JVM 堆（≥16GB→3g、≥8GB→2g、其余 1g）。
 · 不需要安装 Java / Python / Node，运行时已内嵌在包内 jre 目录。
 · 磁盘：压缩包约 336MB，解压后 asean-demo 约 394MB，建议预留 1.5GB 空闲。
 · 联网可选：不联网也能完整演示——AI 降级为离线文案池与规则模板、气象降级为包内模拟数据、
   底图降级为包内预热瓦片，界面来源标签会跟着变成实际生效的通道，不会假装。


四、演示时建议的点击顺序（对应评分点）

 1. 大屏「决策沙盘」→ 点「📡 模拟官方气象推送（85/62mm）」触发气象熔断，
    路线风险着色和推荐会实时变化。
 2. 再点「🧠 AI 决策分析」→ 这一步按通道优先级实时选路：本机装了
    Ollama 就走本地大模型（数据不出本机）；没装时走包内已配好的
    在线 DeepSeek API（标签显示「在线 API·非本地」）；两条都不通则
    自动落到离线文案池与规则模板，结果照样出、流程不中断。
    请注意不要点「⚡ 缓存模式」，那是读取包内预生成文案，不调用模型。
    界面标签分四档如实标注来源：本地大模型 / 在线 API·非本地 /
    离线缓存文案 / 规则模板（预生成场景另标「预生成文案」），
    显示哪一档就是哪一档，不会拿模板文案冒充模型输出。
    本包的 .env.local 已填入申请人的在线模型 Key，无需任何配置就会
    真实调用模型；若这台机器不便于出网，把 DEEPSEEK_FALLBACK_KEY 与
    deepseek.fallback.url 两行一起清空重启即可，系统会自动改用文案池与模板。
    没触发熔断的常态下系统按设计不调模型（避免给出与事实矛盾的推荐），
    此时显示「规则模板」是正常的，不是故障。
    首次调用可能要等几秒到几十秒（在线 API 排队 / 本地模型冷启动加载）。
 3. 顶部一键切换数据源：官方 CRA40 / 公网 Open-Meteo / 离线模拟，
    可以把同一条路线在三种源下各对一遍，看风险着色是否跟着真实雨强变化。
 4. 核验气象请求到底出网去了哪里，浏览器直接打开：
      http://localhost:8080/api/weather/real
        → 返回当前真正生效的数据源 source 与 sourceLabel（本包已填入
          官方 Token，正常情况下这里是 contest-observation／CRA40；若所在
          网络屏蔽官方接口，会自动降级为 open-meteo，同样是真实气象数据，
          不是模拟值）
      http://localhost:8080/api/weather/rate-stats
        → 返回真实回源次数、被节流挡掉的次数、熔断次数、是否处于熔断窗口
    组委会 CRA40 官方接口已随包配好凭证，开箱即可核验，不必再填 Token。
    取数时刻固定为演示视频与答辩材料所用的同一时刻（由包内
    WEATHER_REAL_OBSERVATION_TIME 指定），便于与视频逐段对照；它不是“此刻”
    的实况快照，清空该行则回落到代码默认的 202412312000。
    官方接口有 10 分钟结果缓存与 60 秒最小回源间隔，所以连点"拉取实时气象"
    只有第一次真正出网，后面命中缓存——这是频度合规要求，不是卡住。
 5. 司机端 http://localhost:8080/driver.html 看换线通知与在途车辆的反馈。


五、常见状况

 · 8080 端口被占用 → 程序会自动改用 8081~8089，黑窗里 Address 那一行写的
   就是实际地址，把上面 URL 的端口换成它即可。
 · 第二次双击快很多：已解压过且内容未变的文件会自动跳过。这依赖同目录下
   的 asean-demo.setup.id 标记文件，请不要单独删除它。
 · 界面顶部显示「OSM 未加载」属正常：包内关闭了原始路网加载以免在别人机器
   上占用几百 MB 内存，算路与风险着色用的是包内预置路网，功能完整。
 · 想彻底清理：关掉黑色命令行窗口，然后删除 asean-demo 文件夹、
   asean-demo.setup.id 和这个 exe 即可，系统里不留任何残留。

 级别的影像底图、真实模型推理三条都是真通道，无需现场申请或填写任何密钥。
 代价是凭证随包外发：本包只定向交付评审人员，请勿上传公开网盘、群发链接或
 传到仓库；演示结束后三份凭证会及时轮换／作废。
 凭证若失效、被封或本机不通公网，系统自动降级（官方气象 → 公网 Open-Meteo
 → 离线模拟；天地图 → 包内预热瓦片 → 其余底图；在线推理 → 文案池与规则模板），
 全流程与界面展示仍不受影响，来源标签会如实变成实际生效的通道。
