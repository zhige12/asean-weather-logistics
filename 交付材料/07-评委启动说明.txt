 面向东盟跨境物流的突发气象预警与多路线协同调度平台
 演示程序启动说明 —— 配套文件：asean-demo-setup.exe
═══════════════════════════════════════════════════════════════════════════

一、三分钟跑起来（共 4 步，其中只有第 2 步可能要您点一下）

 1. 把 asean-demo-setup.exe 复制到桌面，或任意一个普通文件夹。
    · 请不要在压缩包、网盘客户端的"预览窗口"里直接双击——那样文件会被
      临时释放到系统临时目录，关闭时被连带删除。程序检测到这种情况会
      主动弹窗提示，不会留下半成品。

 2. 双击 asean-demo-setup.exe。会出现两步进度：
      第 1 步  正在释放演示文件 0% → 100%
      第 2 步  正在展开演示文件（约 10~30 秒）
    进度走完后，exe 所在目录里会自动出现一个 asean-demo 文件夹。
    这一步不需要您点任何按钮，也不需要安装任何软件。

 3. 紧接着自动弹出一个黑色命令行窗口，那就是服务端。
    首次启动要加载路网，窗口里会滚日志，请耐心等 10~30 秒。
    演示期间请一直开着这个窗口，关掉它服务就停止。
    · Windows 防火墙第一次会询问，勾选「专用网络」→「允许访问」。

 4. 约 25 秒后浏览器会自动打开调度大屏。没有自动打开就手动输入：
      调度大屏   http://localhost:8080/
      司机端     http://localhost:8080/driver.html
    建议用 Chrome 或 Edge，进入页面后按一次 Ctrl+F5 刷新一下。


二、如果被打断，只有这两种情况（都是正常现象）

 · 蓝色窗口「Windows 已经保护你的电脑」
   → 点「更多信息」→「仍要运行」。
   原因：本程序未购买商业代码签名。它做的事情只有两件：把跟在自身文件尾
   部的演示数据解压到同目录，然后启动解压出来的 start.bat，不修改系统
   设置、不联网下载、不写注册表。

 · 360／火绒等安全软件把本 exe 隔离或删除，双击没反应
   → 请改用压缩包版 asean-demo-offline.zip（若您收到的材料里没有这个压缩包，
     请联系参赛者补发）：右键「全部提取」，进入 asean-demo 文件夹，
     双击 start.bat。
   两个入口内嵌的内容是逐字节相同的，功能没有任何差别，压缩包形式不会被拦。


三、机器要求

 · Windows 10 版本 1809 及以上，64 位（Windows 11 直接可用）
 · 不需要安装 Java / Python / Node，运行时已内嵌在包内的 jre 目录
 · 磁盘：exe 本身 342MB，解压后 asean-demo 约 394MB；解压瞬间另需约 342MB
   临时空间（完成后自动删除）。建议预留 1.5GB 空闲
 · 内存 4GB 以上
 · 联网可选：不联网也能完整演示——AI 会自动降级为规则模板、气象会自动
   降级为包内模拟数据，界面上的来源标签会跟着变成降级后的名字，不会假装


四、演示时建议的点击顺序（对应评分点）

 1. 大屏「决策沙盘」→ 点「📡 模拟官方气象推送（85/62mm）」触发气象熔断，
    路线风险着色和推荐会实时变化。
 2. 再点「🧠 AI 决策分析」→ 这一步会真实调用大模型。
    请注意不要点「⚡ 缓存模式」，那是读取包内预生成文案，不调用模型。
    界面标签分五档如实标注来源：本地大模型 / 公司内网网关 /
    在线 API·非本地 / 规则模板 / 预生成文案，显示哪一档就是哪一档。
    没触发熔断的常态下系统按设计不调模型（避免给出与事实矛盾的推荐），
    此时显示「规则模板」是正常的，不是故障。
    首次调用可能要等几秒到几十秒（在线 API 排队 / 本地模型冷启动加载）。
 3. 顶部一键切换数据源：官方 CRA40 / 公网 Open-Meteo / 离线模拟，
    可以把同一条路线在三种源下各对一遍，看风险着色是否跟着真实雨强变化。
 4. 核验气象请求确实出网到了组委会官方接口，浏览器直接打开：
      http://localhost:8080/api/weather/real
        → 返回当前真正生效的数据源 source 与 sourceLabel
      http://localhost:8080/api/weather/rate-stats
        → 返回真实回源次数、被节流挡掉的次数、熔断次数、是否处于熔断窗口
    官方接口有 10 分钟结果缓存与 60 秒最小回源间隔，所以连点"拉取实时气象"
    只有第一次真正出网，后面命中缓存——这是频度合规要求，不是卡住。
 5. 司机端 http://localhost:8080/driver.html 看换线通知与在途车辆的反馈。


五、常见状况

 · 8080 端口被占用 → 程序会自动改用 8081~8089，黑窗里 Address 那一行写的
   就是实际地址，把上面 URL 的端口换成它即可。
 · 第二次双击快很多：已解压过且内容未变的文件会自动跳过。这依赖同目录下
   的 asean-demo.setup.id 标记文件，请不要单独删除它。
 · 界面顶部显示「OSM 未加载」属正常：包内关闭了原始路网加载以免在别人机器
   上占用几百 MB 内存，算路与风险着色用的是包内预置路网，功能完整。
 · 想彻底清理：关掉黑色命令行窗口，然后删除 asean-demo 文件夹、
   asean-demo.setup.id 和这个 exe 即可，系统里不留任何残留。
