②风险引擎层气象有什么用 · 转成"能不能走"

实时气象联动判据（逐边取两端较差天气）

小时雨强 ≥ 50 mm/h → 惩罚 100（暴雨）；≥ 20 → 20；风速 ≥ 60 km/h → 50；能见度 < 100m → 50、< 500m → 20；气温 ≥ 35℃ → 8（冷链货损）。台风/强对流双要素：气压 ≤ 990hPa 且风速 ≥ 60km/h → 100，≤ 1000hPa 且 ≥ 40km/h → 50（真实与沙盘共用同一判据，缺要素不误判）。惩罚系数 ≥ 100 即判该边“等效道路中断”，算路时直接跳过

多要素公路风险指数（0–100）

降雨 + 结冰（气温 < 5℃ 且路面潮湿）+ 能见度 + 侧风 + 高温加权压成单一指数，分低/中/高/极高四档并给处置建议与命中因子明细；缺要素不贡献分，不因数据缺失误升级——让"这条路有多危险"不只等于"下没下暴雨"

官方预报 / 沙盘判据（口岸断面）

断面取未来 6h 累计降雨：友谊关阈值随企业风险容忍度取保守 80 / 平衡 100 / 激进 120mm，芒街固定 70mm；降雨源分「GOWFS 预报（真实）」与「模拟参数（可调）」两档并在界面标明；达阈值即注入 penalty=100 参与算路，界面改档即全链路重估

恢复带滞后，不来回翻

80mm 熔断后需降到 75mm 以下才解除（阈值 − 5mm 滞后线）；降雨达 50mm 只进入“关注”态作叙事展示，不注入软惩罚——惩罚是乘数，乘上去会连口岸通关时间一起放大，方案时效就失真了

同一次降雨，为何只封友谊关

友谊关 85mm ≥ 80 → 越限熔断；芒街 62mm < 70 → 未越限可通行。逐边给出越限依据与触发源，不是一刀切

熔断后剩余图重算 + 全要素代价

A*/Dijkstra 毫秒级、可重复执行；输出里程 / 耗时 / 绕行延误 / 油耗 / 通行费 / 通关时效 / 货损金额 / 碳排放；只有全部走廊都搜不出路时才把硬熔断降级为软惩罚兜底搜一次，并在结果里标 corridorAllFused

全域受阻：建议折返 / 等待而非硬闯

判据是路网级的：公路已搜不出任何路径且运河禁航 → 按在途状态出建议：未发车暂缓发车、在途未出境按真实路网折返起点（给里程/耗时）、已出境就近安全停靠等待（折返要重新通关不经济）；同一份 advisory 下发大屏与司机端，两端同时停止自动派单与自动换线

公—水双向互备评估

公路熔断 → 即刻评估运河水运可执行性；水运禁航（能见度 < 1000m 等红线）→ 反向核算公路绕行成本

③AI 智能体层怎么与 AI 交互 · 引擎给边界，模型给文字

职责严格分离

引擎 → 智能体：下传结构化熔断清单与决策边界（哪条边熔断、绕行代价、货损金额），作为提示上下文； 智能体 → 引擎：只回文字（风险解释、方案研判陈述、中越双语预警文案），模型生成的数字一律不采信，所有数值仍由确定性引擎产出。

三个智能体顺序接力

行业知识库提供依据

任一通道不可用都不断流程

货损与到达时间随之改写
